## Release scope

This patch release contains the post-0.8.0 audit remediation and release hardening work documented in `CHANGELOG.md`.

### Functional remediation

- REST organization-analysis response serialization is covered by the corrected response contract.
- Diagnostic failures use meaningful non-zero exit semantics.
- Repository-QA evidence retains concrete dependency/dependent paths.
- Engineering-plan mutation scope is bounded by explicit planned paths.
- Validation failures use controlled CLI errors rather than stack traces.
- Architecture drift reports deterministic dependency-edge changes.

### Release engineering

- Gradle and application version contracts were aligned to `0.8.1`.
- Linux x64, Windows x64, macOS x64, and macOS ARM64 packaging was produced.
- Bundled Java 21 runtime verification was required for packaged artifacts.
- SHA-256 checksums were generated by the release workflow.
- The exact release candidate passed the applicable release certification before publication.
